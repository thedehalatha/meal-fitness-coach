[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let us trace the workflow architecture. First, any user query goes into the security checkpoint node to clean PII and block injections or unsafe medical prompts. If it is clean, it goes to the orchestrator node, which uses AgentTools to run our two specialized sub-agents: the meal planner agent and the workout planner agent. These sub-agents query our local Model Context Protocol server tools to fetch recipes, retrieve exercise guidelines, calculate macro targets, or organize shopping lists. Once the sub-plans are gathered, the orchestrator compiles them into a unified CoachPlan, which suspends at the hitl_approval_node to wait for human confirmation.
